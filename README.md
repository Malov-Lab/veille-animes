# Ma veille animés

Page personnelle de suivi d'animés : prochains épisodes, retard, suites annoncées,
suggestions basées sur mes notes, nouveautés de la saison.

Page statique, sans serveur ni base de données. Les données publiques viennent de
l'API AniList, interrogée directement par le navigateur à chaque ouverture.

Les notes, les ajouts manuels et les séries écartées restent dans le stockage
local du navigateur : ils ne sont ni publiés, ni envoyés nulle part.
